# Frontend — Phase-II scope

No frontend exists yet, and Phase-I does not require one. The Phase-I interface is
the `kgcr` CLI (see [../backend/kgcr/cli.py](../backend/kgcr/cli.py)).

Planned for Phase-II: a results view over `results/` — the DF-7 contrast evidence
and the per-field reliability diagram from the intent reconstructor — served
alongside the review output, with the audience modes (`architect` / `auditor` /
`learner`) that FD-06 specifies for explanation rendering.
