file rather than an edit to an opaque binary, and the PNG and SVG come from the same layout code so
they cannot drift apart.

```bash
python architecture/make_diagrams.py
```

## Honest reading of Diagram 1

Diagram 1 is a **planning** diagram, which is what Phase-I asks for, and it is labelled as such on
the diagram itself. What exists today is the AWS Budgets and cross-account IAM Terraform in
[`src/aws/`](../src/aws/) — authored, not yet applied. The analysis pipeline currently runs locally
in Python under [`src/backend/`](../src/backend/). The gap between the planned services and the
running system is stated on the diagram rather than left for a reviewer to discover.
